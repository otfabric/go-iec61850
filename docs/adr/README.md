# Architecture decision records

Decisions of this repository that are hard to reverse, numbered in order. A
record is not edited after it is accepted, except to set its status; a later
record supersedes it instead.

References of the form `ADR-00NN` elsewhere in this repository (for example
ADR-0009 nested modules, ADR-0010 secure defaults, ADR-0012 own-stack images)
are organisation records in
[otfabric/engineering](https://github.com/otfabric/engineering/tree/main/docs/adr),
not these.
